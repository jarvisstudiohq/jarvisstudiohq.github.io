This website

This website uses no cookies, no analytics, no advertising and no trackers, and it has no forms. It stores nothing in your browser.

Its fonts (Grandstander, Fredoka and Ultra) load from Google Fonts, so your browser asks Google’s servers for them, as it does on any site that uses them. The site is hosted on GitHub Pages, and GitHub may keep basic logs of visits, such as IP addresses, under its own privacy statement. We don’t receive or use those logs.

If you email us, we use your message and email address only to answer you.

See also the accessibility statement.
